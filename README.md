# قرص الألوان — متجر تيشيرتات بواجهة ثلاثية الأبعاد

الصفحة الرئيسية قرص دوّار: نسخ من نفس التيشيرت موزّعة على حلقة، كل واحدة بلون.
تلفّ القرص بالسحب أو العجلة أو الأسهم، وباختيار اللون الأمامي تنتقل الكاميرا
إلى مشهد منتج مقرّب فيه السعر والمقاسات والشراء.

المنظومة: Next.js 15 (App Router) · React Three Fiber · Tailwind v4 · Supabase.
الواجهة عربية بالكامل باتجاه RTL، والعملة دينار عراقي.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
```

**يعمل فوراً بلا أي إعداد**: بدون مفاتيح Supabase يقرأ الكتالوج من
`data/products.ts`، وبدون ملف الموديل يستخدم مجسّماً مولّداً بالكود.

| الأمر | الغرض |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج |
| `npm test` | اختبارات رياضيات القرص |
| `npm run lint` | ESLint |

## متغيّرات البيئة

انسخ `.env.example` إلى `.env.local`. كل مجموعة اختيارية وتفعّل ميزتها وحدها:

| المتغيّر | بدونه | معه |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` + `..._ANON_KEY` | الكتالوج من `data/products.ts`، ولوحة الإدارة معطّلة | الكتالوج من قاعدة البيانات، والمصادقة تعمل |
| `SUPABASE_SERVICE_ROLE_KEY` | إنشاء الطلبات يُرجع 503 | الطلبات تُحفظ ويُخصم المخزون |
| `NEXT_PUBLIC_ZAINCASH_NUMBER` / `NEXT_PUBLIC_FASTPAY_NUMBER` | الدفع عند الاستلام فقط | يظهر خيار «تحويل إلى محفظة» بالأرقام المضبوطة |
| `NEXT_PUBLIC_USE_GLB=1` | مجسّم مولّد بالكود | `public/models/tshirt.glb` |

مفتاح الخدمة يتخطّى سياسات الصفوف — لا يُوضع في متغيّر يبدأ بـ`NEXT_PUBLIC` أبداً.

## إعداد Supabase

1. أنشئ مشروعاً، ثم شغّل في محرّر SQL بالترتيب:
   - `supabase/migrations/0001_catalog.sql`
   - `supabase/migrations/0002_orders.sql`
   - `supabase/migrations/0003_iraq.sql` (الدينار العراقي وأعمدة التحويل)
   - `supabase/seed.sql` (بيانات أوّلية، آمنة للتكرار)
2. أنشئ مخزناً **خاصاً** باسم `receipts` من تبويب Storage (لصور إيصالات
   التحويل). الرفع والقراءة يتمّان بمفتاح الخدمة، فلا يحتاج أي سياسة.
3. أضف المفاتيح الثلاثة إلى `.env.local`.
4. للوحة الإدارة: أنشئ مستخدماً في **Authentication**، ثم أضف معرّفه إلى جدول
   المدراء:
   ```sql
   insert into public.admins (user_id) values ('<UUID المستخدم>');
   ```
5. ادخل على `/admin`.

## الدفع

بوابات البطاقات العالمية (Stripe وأمثالها) لا تخدم العراق، فالطريقتان هنا:

1. **الدفع عند الاستلام** — مفعّل دائماً.
2. **تحويل إلى محفظة** — يظهر فور ضبط `NEXT_PUBLIC_ZAINCASH_NUMBER` أو
   `NEXT_PUBLIC_FASTPAY_NUMBER`. العميل يحوّل إلى الرقم المعروض، ثم يرفع صورة
   الإيصال من صفحة الطلب، وأنت تراجعها من `/admin/orders` وتغيّر الحالة إلى
   «مدفوع».

المخزون يُحجز فور تسجيل الطلب في الحالتين. إن رفضت طلباً حوّل حالته إلى «ملغى»
وأعد المخزون يدوياً من `/admin/products`.

الإيصالات في مخزن خاص، وتُعرض في لوحة الإدارة عبر روابط موقّعة صالحة نصف ساعة.

## ملف الموديل

ضع الملف في `public/models/tshirt.glb` واجعل `NEXT_PUBLIC_USE_GLB=1`. شروطه:

- محور Y للأعلى، والوجه نحو `+Z`.
- لون أساس أبيض أو رمادي **بلا نسيج ملوّن مخبوز**، وإلا لن يتغيّر اللون.
- يفضّل بلا ضغط Draco (وإلا انسخ ملفات فكّ الضغط إلى `public/draco/`).

المقياس والاتجاه يُطبَّعان تلقائياً في `lib/normalize-object.ts`، فلا تحتاج
لضبط أرقام يدوياً. التبديل يمسّ `components/showroom/TShirtModel.tsx` وحده.

## قرارات تصميمية تستحق المعرفة

- **زاوية الدوران في `ref` لا في حالة React**: تحديثها ٦٠ مرة بالثانية عبر
  `setState` يعني ٦٠ إعادة توفيق للشجرة كلها.
- **`spin` غير مطبَّع أبداً**: يتراكم بحرية، فيصبح التثبيت على أقرب خانة محلياً
  دائماً وتختفي مشكلة الالتفاف حول ٢π من جذورها.
- **لا استنساخ لمشهد الـGLTF**: نستخرج الهندسة ونرسمها إعلانياً، فالمواد
  يُنشئها R3F لكل نسخة. `clone(true)` يشارك المادة بالمرجع فيلوّث الكاش العالمي.
- **قائد واحد للكاميرا في كل لحظة**: `lookAt` اليدوي و`OrbitControls.update()`
  في الإطار نفسه يعطيان ارتجافاً بمعدل الإطارات.
- **لا يُوثق بأي سعر يرسله العميل**: كل سعر يُقرأ من قاعدة البيانات في
  `lib/orders/quote.ts` قبل الإدراج.
- **`MAX_DELTA`**: يمنع قفز المشهد بعد تبديل التبويب، وثمنه أن الحركة تتباطأ عن
  الساعة على الأجهزة البطيئة جداً.

## ما يبقى مفتوحاً

- التجربة تعرض منتجاً واحداً؛ صفحات منتجات متعددة تحتاج مسار `/product/[slug]`.
- إلغاء الطلب لا يعيد المخزون تلقائياً.
- لا تكامل مع بوابة زين كاش أو فاست باي الرسمية؛ التحويل يدوي بمراجعة بشرية.
- لا يوجد حساب للعميل: صفحة الطلب تُفتح برابط يحمل معرّفاً عشوائياً.
- رفع صور المنتجات إلى Supabase Storage غير مضاف بعد.
